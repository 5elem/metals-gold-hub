# metals-gold-hub

Ежедневный **дайджест по золоту (Au)** от агента **METALS NEWS**.

Таймзона: **Europe/Tallinn**. Публикация: **каждое утро** (рекомендуется 09:00).

## Единственный вход

Источник правды — **только METALS NEWS**.

- METALS NEWS каждый день кладёт сюда **готовый дайджест** по золоту: что важнее (ранжирование уже внутри текста), факты и **рабочие ссылки** на первоисточники.
- Агенты сайта **не анализируют** рынок сами и **не ранжируют** заново.
- Они **берут дайджест как есть**, переводят / трансформируют в статью на нужном языке и публикуют.
- Агенты сайта **не добавляют свои источники** сверх списка из `sources.md`.

## Структура

```
digests/YYYY-MM-DD/
  digest.md    — полный текст дайджеста METALS NEWS (RU)
  sources.md   — нумерованный список первоисточников со ссылками
latest.json    — указатель на свежий день
```

Устаревшие форматы (`articles/…` карточки, корневые `YYYY-MM-DD/article.md`) **не использовать**.

## Как агентам сайта забирать

1. Прочитать `latest.json` → поля `date`, `digest`, `sources`.
2. Скачать `digest.md` — это весь контент для статьи.
3. Скачать `sources.md` — канонический список ссылок; не расширять своим поиском.
4. Перевести / сверстать статью, сохранив смысл ранжирования и URL из `sources.md`.

```bash
curl -sL https://raw.githubusercontent.com/5elem/metals-gold-hub/main/latest.json
curl -sL https://raw.githubusercontent.com/5elem/metals-gold-hub/main/digests/2026-09-23/digest.md
curl -sL https://raw.githubusercontent.com/5elem/metals-gold-hub/main/digests/2026-09-23/sources.md
```

## Формат digest.md

Живой русский текст METALS NEWS, обычно:

1. Короткий главный вектор (что важнее всего за ~24ч)
2. Цена / рынок (spot, %, Fed, DXY, комментарии) — по убыванию важности
3. Драйверы и горизонт 1–7 дней
4. Без «купи/продай», без выдуманных цифр

## Формат sources.md

Нумерованный список: `N. Название — URL`  
Только то, на что опирается `digest.md`.

## Кто пишет в хаб

Только **METALS NEWS** (утренний routine). Остальные агенты — только читатели.
