# metals-gold-hub

Центральный хаб **карточек** по золоту (Au) для агентов Deniss.

Таймзона: **Europe/Tallinn**. Обновление: **каждое утро** (рекомендуется 09:00).

## Модель (важно)

- Агенты-сборщики (в т.ч. **METALS NEWS**) тянут новости и показатели по золоту **на любом языке** (EN, ZH, … без ограничений).
- Отбирают лучшие по качеству и значимости, **ранжируют**.
- В репозиторий кладут **не готовые статьи**, а **структурированные карточки**.
- Агенты сайта сами подхватывают карточки, **переводят и трансформируют** в статьи на нужном языке.

METALS NEWS: собрать лучшие сигналы/показатели → решить, что важнее → положить карточки в хаб.  
Трансформацию в статьи делают другие агенты.

## Структура

```
articles/YYYY-MM-DD/
  01-….md     — карточка (номер = ранг: 01 важнее 02)
  02-….md
  …
  index.json  — список карточек дня + ранжирование
latest.json   — указатель на свежий день
```

Старая папка `YYYY-MM-DD/` в корне (готовые статьи) **устарела** — не использовать.

## Шаблон карточки (markdown)

```markdown
---
id: 2026-09-23-01
rank: 1
significance: high          # high | medium
date: 2026-09-23
timezone: Europe/Tallinn
lang: en                    # язык оригинала карточки (summary)
source_name: Reuters
source_url: https://…
metric: optional            # например spot_au_usd, dxy — если это показатель
---

# <Заголовок оригинала>

## Summary
Краткое содержание **на языке оригинала** (2–5 предложений). Цены и % только из первоисточника.

## Why it matters
1–2 предложения: почему это важно для золота / рынка сегодня (нейтрально, без «купи/продай»).
```

## Как агентам сайта забирать

1. Прочитать `latest.json` → `date`, `path`.
2. Прочитать `articles/{date}/index.json` → упорядоченный список карточек.
3. Скачать каждый `.md` по `file`.
4. Перевести / собрать статью на целевом языке, сохранив `source_url`.

```bash
curl -sL https://raw.githubusercontent.com/5elem/metals-gold-hub/main/latest.json
curl -sL https://raw.githubusercontent.com/5elem/metals-gold-hub/main/articles/2026-09-23/index.json
```

## Источники (ориентир)

Kitco, Reuters, GlobeNewswire, Fed/WGC/WPIC, официальные сайты ЦБ и майнеров. Любой язык оригинала допустим; в карточке `lang` = язык summary.

## Правила качества

- Без выдуманных цифр; каждая цифра привязана к `source_url`.
- Без «купи/продай».
- `significance: high` — двигает цену или меняет нарратив дня; `medium` — полезный контекст / горизонт 1–7 дней.
- Ранг в имени файла (`01-`, `02-`) и в `index.json` должен совпадать.
