# metals-gold-hub

Центральный хаб ежедневных черновиков статей по **золоту (Au)** для агентов Deniss.

Таймзона: **Europe/Tallinn**. Публикация: **каждое утро** (рекомендуется 09:00).

## Зачем это

Агент-разведчик каждый день кладёт сюда готовый черновик статьи (заголовок + 2 блока).  
Другие агенты и читатели **подхватывают материал отсюда** по расписанию и публикуют на сайте / в баннере / в рассылке.

## Структура

```
YYYY-MM-DD/
  article.md   — готовый текст статьи (RU)
  meta.json    — метаданные: дата, таймзона, источники, статус
latest.json    — указатель на самый свежий день (удобно агентам)
```

## Как агентам забирать контент

1. Прочитать `latest.json` в корне → взять `date` и `path`.
2. Скачать `/{date}/article.md` — это готовый черновик к публикации.
3. При необходимости сверить источники из `/{date}/meta.json` → `sources`.
4. Если `latest.json` старше ~24 часов или отсутствует — собрать данные с веб-первоисточников (Kitco, Reuters, WGC и т.д.) и **залить новый день** в этот же репозиторий.

### Пример (curl / gh)

```bash
# указатель
curl -sL https://raw.githubusercontent.com/5elem/metals-gold-hub/main/latest.json

# статья за день
curl -sL https://raw.githubusercontent.com/5elem/metals-gold-hub/main/2026-09-23/article.md
```

Или через API:

```bash
gh api repos/5elem/metals-gold-hub/contents/latest.json --jq .content | base64 -d
```

## Формат article.md

- **Заголовок** (H1)
- **Блок 1 — цена и рынок**: spot Au, % за сутки, драйверы (Fed/DXY/комментарии), 1–2 ссылки
- **Блок 2 — драйверы и горизонт**: события на 1–7 дней, safe-haven vs доминирующий фактор, 1–2 ссылки
- Язык: русский. Без «купи/продай». Без выдуманных цифр.

## Формат meta.json

```json
{
  "date": "YYYY-MM-DD",
  "timezone": "Europe/Tallinn",
  "metal": "Au",
  "title": "...",
  "sources": ["https://...", "https://..."],
  "github_feed_used": false,
  "published_at": "YYYY-MM-DDTHH:MM:SS+03:00"
}
```

## Кто пишет в хаб

Утренний агент METALS NEWS (или другой назначенный) после сбора ~24ч сигналов создаёт папку дня и обновляет `latest.json`.

## Лицензия / использование

Внутренний контент-хаб для агентов и каналов публикации владельца. Цифры всегда с первоисточниками в статье.
